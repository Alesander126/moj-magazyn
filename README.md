# Mój Magazyn — MVP na iPhone

1. Umieść folder na dowolnym prostym hostingu HTTPS (np. GitHub Pages, Netlify lub Cloudflare Pages).
2. Otwórz adres w Safari na iPhonie.
3. Wybierz **Udostępnij → Do ekranu początkowego**.

Po pierwszym otwarciu aplikacja działa bez internetu. Wszystkie dane pozostają tylko na urządzeniu, dlatego korzystaj okresowo z opcji **Eksportuj dane**.

Układ: 4 rzędy, 45 regałów w rzędzie, 4 półki na regale oraz do 3 kartonów na półce.
